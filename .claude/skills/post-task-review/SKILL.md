# Ревью после реализации задачи

Выполняется после того, как код написан и проверки (`type-check`, `lint`, тесты) проходят.
Три шага строго по порядку. Задача не готова, пока не пройдены все три.

## Шаг 1 — Code review
- Запустить скил `/code-review` по текущему диффу.
- Подтверждённые ошибки исправить; спорные находки — вынести пользователю с пояснением.
- После исправлений снова прогнать `type-check`, `lint`, тесты.

## Шаг 2 — Принципы Karpathy
Пройти дифф по скилу `karpathy-guidelines` и проверить каждый пункт:
- **Допущения** — все неочевидные допущения названы пользователю.
- **Простота** — нет функций, абстракций и настроек сверх запроса; нет обработки невозможных сценариев.
- **Точечность** — каждая изменённая строка следует из запроса; соседний код не «улучшен» попутно;
  неиспользуемое, созданное своими правками, удалено.
- **Критерий готовности** — есть проверяемый критерий, и он выполнен.
Нарушения исправить.

## Шаг 3 — Финальное ревью
- Прочитать итоговый дифф целиком ещё раз.
- Убедиться, что исправления шагов 1–2 ничего не сломали и соответствуют `CLAUDE.md` и `.claude/rules/`.
- Финально прогнать `type-check`, `lint`, тесты.

## Отчёт пользователю
По одной-две строки на шаг:
```
1. Code review: <что найдено / исправлено, или «замечаний нет»>
2. Karpathy: <нарушения и правки, или «соответствует»>
3. Финальное ревью: <результат, статус проверок>
```
